# ADR-0001. Форк OpenCode + Hub + нативный OAuth для ТЭГ

Дата: 2026-08-18. Статус: принято.

Контекст и решение — см. `docs/req-mvp.md` (rev 0.2, §1, §4). Ключевые развилки:

1. **Витрина внутри приложения** (форк OpenCode) вместо только веб-страницы — потому что цель
   продукта «как в Claude», а `/mcps` OpenCode показывает лишь имя и статус.
2. **Hub как стандартный MCP authorization server** (фасад) для существующих MCP AI Lab —
   серверы не меняем, любые MCP-клиенты подключаются по спецификации; токены систем — в Hub.
3. **ТЭГ — нативный OAuth** через FastMCP 3.4.6 `OAuthProxy` — эталон для будущих серверов
   каталога; Hub для него только каталог.
4. **Существующие облачные MCP не трогаем**; их нативный OAuth (GitLab MCP ≥ 2.1.10,
   Atlassian MCP) — зависимость от AI Lab, после MVP.
5. **Ключ LiteLLM — постоянный**, создаётся Hub'ом через CLI-SSO + `/key/generate`;
   команда LiteLLM выбирается пользователем при входе.
6. **GitLab (platform/coderepo) для кода — позже**; сейчас всё в GitHub.
