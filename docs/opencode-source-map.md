## 3. Сервер: MCP и конфиг
- `/packages/opencode/src/mcp/index.ts` (953 стр.): статусы `Status` = union `connected|disabled|failed{error}|needs_auth|needs_client_registration{error}` (стр. 95-119). `connect` (610) = `createAndStore(name, {...mcp, enabled:true})` — только in-memory `s.config`; `disconnect` (615) закрывает клиент и ставит `{status:"disabled"}`. `startAuth` (748), `authenticate` (813 — `open(authorizationUrl)`, при неудаче событие `BrowserOpenFailed` стр. 69/855), `finishAuth` (870), `removeAuth`, `getAuthStatus`.
- `/packages/opencode/src/mcp/auth.ts`: токены/clientInfo/PKCE в `Global.Path.data/mcp-auth.json` (стр. 37), запись 0o600.
- `/packages/opencode/src/mcp/oauth-provider.ts`: `OAUTH_CALLBACK_PORT = 19876`, `OAUTH_CALLBACK_PATH = "/mcp/oauth/callback"` (стр. 11-12), redirect по умолчанию `http://127.0.0.1:19876/mcp/oauth/callback`, override через `oauth.redirectUri`/`oauth.callbackPort`.
- `/packages/opencode/src/mcp/oauth-callback.ts`: локальный `http`-сервер, `ensureRunning` (144), `waitForCallback` (172), `cancelPending` (188).
- `/packages/opencode/src/config/config.ts`: `.well-known` — стр. 356-394 (для auth-записей типа `wellknown` тянется `<url>/.well-known/opencode`, затем `remote_config`, merge как «global»). Запись конфига: `update` (623) пишет `<project dir>/config.json`; `updateGlobal` (636) — `globalConfigFile()` (139: `opencode.jsonc` → `opencode.json` → `config.json` в `Global.Path.config`), для `.jsonc` — точечный патч `patchJsonc` (149).
- **`mcp.<name>.enabled` из UI не персистится**: тоггл только runtime. Persist происходит при `opencode mcp add` — `/packages/opencode/src/cli/cmd/mcp.ts` `addMcpToConfig` (423-440, `modify(text, ["mcp", name], …)`), либо ручным редактированием / `PATCH /config` → `Config.update`.
